About

Built to remove one excuse for not shipping.

This API exists so that building something Quran-related doesn't start with typing out 6,236 ayahs into a spreadsheet. Generate a key, call an endpoint, get structured data back.

It's a small, self-serve project — no accounts, no billing, no dashboard to configure. Keys expire on their own, and the whole thing is built to stay online without hand-holding.

Dataset
6,236 valid ayahs, each tagged with surah number, surah name, ayah number, page, para (juz), and PIP.
Built by
Najiful Islam — an independent developer's project, built for easy Quran data access.
Stack
Node.js + Express for the API, MongoDB (via Mongoose) for key and user persistence, Firebase Authentication for sign-in.
Rate limits
Every key allows 100 requests. At creation you choose how long it lasts — 15 days, 1 month, 6 months, or no expiration. Each IP can hold up to 5 active keys, and each account up to 10.
Uptime
The /health endpoint reports server and database status, and is monitored to keep the service awake.
