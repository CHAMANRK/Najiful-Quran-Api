Documentation

Every endpoint, in plain terms.

A REST API over the full Quran text — 6,236 ayahs, indexed six different ways. Everything but key generation needs a Bearer token.

Authentication

Generate a key on the home page, then send it as a Bearer token on every request.

curl https://your-api-domain.com/api/quran/1/1 \
  -H "Authorization: Bearer najeef_chaman_<your-key>"

Access
POST/api/key

Generates a new API key. No auth required. Max 5 active keys per IP.

Example response 
{
  "success": true,
  "apiKey": "najeef_chaman_a58921...",
  "expiresIn": "6 hours",
  "maxRequests": 100
}
GET/api/validate

Checks whether your key is still valid and how many requests remain.

GET/health

Server and database status. No auth required — useful for uptime monitors.

Reading the Quran
GET/api/quran/:surah/:ayah

One exact ayah, by surah number and ayah number.

surahSurah number, 1–114
ayahAyah number within that surah
Example 
GET /api/quran/1/1

{
  "success": true,
  "data": {
    "surah_name": "Al-Faatiha",
    "surah_number": 1,
    "ayat_no": 1,
    "text": "بِسْمِ ٱللَّهِ...",
    "page": 1, "para": 1, "pip": 1
  }
}
GET/api/quran/surah/:surah

Every ayah in a surah, by its number.

surahSurah number, 1–114
GET/api/quran/surah-name/:name

Every ayah in a surah, by its name instead of number. Case-insensitive.

namee.g. "Al-Faatiha", "Al-Baqara"
GET/api/quran/ayat/:ayah

Every ayah across the whole Quran that shares this ayah number — spans every surah.

ayahAyah number to match
GET/api/quran/para/:para

Every ayah in a para (juz), 1 through 30.

paraPara number, 1–30
GET/api/quran/page/:page

Every ayah on a given mushaf page.

pagePage number
GET/api/quran/pip/:pip

Every ayah matching a PIP value (your dataset's custom index field).

pipPIP value
GET/api/quran/search?q=

Full-text search inside ayah text. Matches Arabic substrings in the ayah body, not surah names. Capped at 100 results.

qSearch string (URL-encoded)
Quiz
GET/api/quiz/question

Returns a random ayah and four surah-number options — one correct. Stays valid for 10 minutes.

Example response 
{
  "success": true,
  "questionId": "7f3354d5...",
  "question": "This Ayah belongs to which Surah?",
  "ayah": "خُذِ ٱلْعَفْوَ...",
  "options": [39, 7, 35, 11]
}
POST/api/quiz/answer

Submit an answer for a question ID. Each question can only be answered once.

questionIdID from /api/quiz/question
answerYour chosen surah number
Errors
400Malformed request — check your parameters.
401Missing, invalid, or expired API key.
404No matching data found.
429Rate limit reached — key's 100 requests, or IP's 5-key cap.
500Server-side error. Check /health.
